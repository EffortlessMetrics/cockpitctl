# Tutorials

Tutorials are **learning-oriented** lessons that take you through a series of steps to complete a project. They help you get started and build confidence.

## Available Tutorials

### [Getting Started](getting-started.md)

Your first run with cockpitctl. You'll learn:
- How to install cockpitctl
- What sensor receipts look like
- How to run `cockpitctl ingest`
- How to interpret the output

### [First Sensor Integration](first-sensor-integration.md)

Add cockpitctl to a real repository. You'll learn:
- How to structure your artifacts directory
- How to run sensors and save receipts
- How to invoke cockpitctl in CI

### [Adding Policy](adding-policy.md)

Create and configure `cockpit.toml`. You'll learn:
- Policy file structure
- How to mark sensors as blocking
- How to configure missing receipt behavior
- How to set budgets and section order

## Prerequisites

- Rust toolchain (for building from source) or a pre-built binary
- Basic familiarity with CI/CD concepts
- A terminal/command line
